# Lista do przeczytania — 2026-10-23
Temat: ai, llm, agent.

## 1. [American Express unveils framework to prevent unauthorised AI agent payments](https://www.digitaltoday.co.kr/en/view/114078/american-express-unveils-framework-to-prevent-unauthorised-ai-agent-payments)
Amex przedstawił mechanizm „Intent Intelligence": klient przez API określa warunki zakupu (sprzedawca, maksymalna kwota, produkt), uwierzytelnia się i zatwierdza taką intencję. System wystawia Intent ID oraz token dowodu intencji, za pomocą którego agent uzyskuje dane płatnicze — nigdy nie widząc numeru karty. Całość ma też zachować ślad tego, co faktycznie zostało zatwierdzone, na wypadek sporu.
**Dlaczego warto:** To konkretny wzorzec „autoryzacji z limitem" dla agentów kupujących w imieniu użytkownika — rozwiązuje to samo, co blokady Schwaba czy Amazona, ale od strony infrastruktury płatniczej.

## 2. [AdaExploreBench: Benchmarking LLM Agents for Proactive Exploration and Test-time Adaptation in Evolving Environments](https://arxiv.org/abs/2610.25950)
Benchmark umieszcza agentów LLM w środowiskach decyzyjnych, w których ukryte reguły zmieniają się bez ostrzeżenia, i sprawdza, czy agent to zauważy i dostosuje strategię. Według doniesień prasowych o pracy żaden z ośmiu testowanych modeli nie przekroczył ok. 70% skalibrowanej trafności, a w sporej części epizodów agenci oceniali reguły tak samo przed zmianą i po niej (liczby nie zweryfikowane w oryginale).
**Dlaczego warto:** Dryf reguł to codzienność wdrożeń produkcyjnych — benchmark pokazuje, że „proaktywna eksploracja" wciąż jest słabym punktem agentów.

## 3. [Quant-Arena: Benchmarking LLM Agents for Quantitative Trading Research](https://arxiv.org/abs/2610.30113)
Praca ocenia agentów LLM nie jako traderów wykonujących transakcje, lecz jako badaczy ilościowych: mają formułować hipotezy i testować je na danych historycznych. Jest to jedna z najnowszych prac z serii benchmarków agentowych z października 2026 (zgłoszona 21.10). Streszczenie oparte wyłącznie na opisie z wyników wyszukiwania — pełny tekst nie był dostępny.
**Dlaczego warto:** Ocenianie agentów na całym procesie badawczym (hipoteza → test → wnioski) bliżej oddaje realną pracę analityka niż testy pojedynczych decyzji.
